## Overview

A collection of UPS optimized smelters (using lead / follower)

Defaults to uncommon materials, but can be changed in the blueprint parameters. Make sure to change them to the quality you are using otherwise the inserter throttling won't work.

More Info - https://github.com/abucnasty/factorio-benchmarks/tree/master/benchmarks/inserter-clocking-methods
